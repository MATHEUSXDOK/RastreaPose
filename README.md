# RastreaPose

## Integrantes
- Matheus Coelho  
- Caio Serpa  

O RastreaPose é um aplicativo web desenvolvido para consultar o clima de qualquer cidade ao redor do mundo de forma rápida e prática.  
Ele utiliza a API do OpenWeatherMap para fornecer informações precisas sobre temperatura e condições do céu.

## Objetivo
Oferecer uma ferramenta simples e intuitiva, ideal para quem deseja acompanhar o clima na sua cidade ou em qualquer outro lugar.
